CÓMO USAR EL GENERADOR DE CONSTANCIAS Y QR
=======================================

Contenido de esta carpeta:
- constancias_gui.py       -> INTERFAZ GRÁFICA (recomendado, ábrelo con doble clic o "python3 constancias_gui.py")
- generar_constancias.py   -> versión de consola, solo modo Constancias (para quien prefiera línea de comandos)
- core/                    -> motor compartido por los dos anteriores, dividido en módulos (no lo borres, ambos lo necesitan)
- gui/                     -> el código de la interfaz gráfica, dividido en módulos (lo usa constancias_gui.py)
- plantilla.jpeg           -> tu diseño de constancia de ejemplo
- datos_ejemplo.xlsx       -> Excel de ejemplo, solo para que veas el formato
- constancias_gui.spec     -> receta para compilar el programa como .exe de Windows (ver paso 10)
- VERSION                  -> número de versión actual del programa (ver paso 11)
- configuracion_actualizaciones.py -> aquí pones la URL de tus actualizaciones (ver paso 11)

El código está organizado en dos paquetes para que ningún archivo sea
demasiado largo — si algún día quieres editar algo, aquí está el mapa:
    core/constancias.py      -> Config, arma el texto sobre la plantilla, procesa el Excel
    core/qr.py                -> ConfigQR, detecta el recuadro y pega el QR en la plantilla
    core/lineas.py             -> detección automática/manual de la línea del nombre
    core/correo.py             -> envío por SMTP con adjunto, cuentas y límite diario
    core/actualizaciones.py    -> revisar/descargar/aplicar actualizaciones del .exe
    core/fuentes.py            -> carga de tipografías
    core/utils.py              -> nombres de archivo, columnas de Excel, guardar PDF
    core/base_dir.py           -> carpeta base del programa (script normal o .exe compilado)
    gui/app.py                 -> arma la ventana principal y el menú "Ayuda"
    gui/panel_constancias.py   -> todo el panel del modo Constancias
    gui/panel_qr.py            -> todo el panel del modo QR
    gui/comunes.py             -> layout general, cola de progreso, drag & drop
    gui/dialogos.py            -> ventanas de marcar línea/recuadro y agregar cuenta
    gui/actualizaciones_ui.py  -> diálogo de aviso de actualizaciones
    gui/dnd.py                 -> soporte de arrastrar y soltar (opcional)
    gui/estilos.py, gui/rutas.py -> colores y rutas de archivo

La interfaz tiene DOS MODOS, seleccionables con los botones de arriba:
  Constancias (Excel)     -> escribe nombre + matrícula sobre una plantilla
  Códigos QR (carpeta)    -> pega imágenes de QR ya generadas sobre una plantilla

1) INSTALA LO NECESARIO (solo la primera vez)
   /usr/bin/python3 -m pip install pandas openpyxl pypdf pillow numpy --break-system-packages

   Si al abrir la interfaz te marca "No module named tkinter", instala además:
   sudo apt install python3-tk

   OPCIONAL (para poder arrastrar archivos a la ventana en vez de usar
   "Examinar…" cada vez):
   /usr/bin/python3 -m pip install tkinterdnd2 --break-system-packages
   Si no la instalas, el programa funciona exactamente igual, solo que
   sin esa comodidad — todos los botones "Examinar…" siguen funcionando.

2) ABRE LA INTERFAZ GRÁFICA
   python3 constancias_gui.py

3) USO EN CONSOLA (sin interfaz, solo modo Constancias)
   python3 generar_constancias.py datos.xlsx
   Opcional: --plantilla otra_plantilla.jpeg --salida carpeta_salida --hoja 0
             --col-nombre "Nombre" --col-matricula "Matrícula"

4) RESULTADO
   Se crea la carpeta de salida con:
   - Modo Constancias: un PDF por persona (Constancia_NombreApellido.pdf)
     + Constancias_TODAS.pdf con todas juntas.
   - Modo QR: una IMAGEN PNG por QR (se abre con cualquier visor de
     fotos, se puede mandar por WhatsApp, subir a redes, etc.), con el
     mismo nombre que traía la imagen original (Juan_Perez_214578.png)
     + un QRs_TODOS.pdf con todas juntas, solo por si las quieres
     mandar a imprimir de un jalón (no es el resultado principal).

5) POSICIÓN AUTOMÁTICA (se adapta a cualquier plantilla, en los dos modos)
   No hay coordenadas fijas en el código. Cada vez que eliges una
   plantilla, el programa busca solo dónde va el texto/QR y lo acomoda
   centrado, con el tamaño que mejor quepa.

   En la interfaz verás uno de estos mensajes junto a "Posición del
   nombre" / "Posición del QR":
     Detectada/Detectado automáticamente   -> todo bien, no hay que hacer nada
     Marcada/Marcado manualmente por ti    -> estás usando una marca manual
     Aviso: no se detectó                  -> usa el botón de marcar manualmente

   Si con una plantilla nueva el texto o el QR queda chueco, encimado,
   o fuera de lugar en la vista previa:
     1. Presiona "Marcar línea manualmente" (constancias) o "Marcar
        recuadro manualmente" (QR).
     2. En constancias: haz clic en el INICIO de la línea (justo
        después de "A:") y luego en el FINAL de la línea.
        En QR: haz clic en la esquina SUPERIOR IZQUIERDA del recuadro
        y luego en la INFERIOR DERECHA.
     3. Presiona "Guardar línea" / "Guardar recuadro".
   Esa marca queda guardada para ESA plantilla exacta (aunque cierres
   el programa), y se puede quitar con "Volver a automático".

   Las marcas manuales se guardan en ".constancias_lineas.json"
   (Constancias) y ".constancias_cajas_qr.json" (QR) en esta misma
   carpeta — no los borres si quieres conservar tus ajustes.

6) ENVIAR LAS CONSTANCIAS POR CORREO (opcional, solo modo Constancias)
   En la interfaz, dentro del modo Constancias, marca la casilla
   "Enviar también por correo a cada persona". Ahí abajo verás la lista
   de "Cuentas guardadas" (empieza vacía) con estos botones:

     • Agregar cuenta: abre una ventanita para dar de alta una cuenta
       remitente:
         - Alias: un nombre para identificarla tú (ej. "Mi Gmail").
         - Correo: la dirección que va a mandar los correos.
         - Contraseña de app: OJO, si usas Gmail esto NO es tu
           contraseña normal. Tienes que:
             1. Activar la verificación en dos pasos en tu cuenta de
                Google (myaccount.google.com/security).
             2. Ir a myaccount.google.com/apppasswords y generar una
                "contraseña de aplicación" (son 16 letras sin espacios).
             3. Pegar esa contraseña de 16 letras en este campo.
         - Límite diario: cuántos correos puede mandar esa cuenta antes
           de que el programa pase solo a la siguiente (Gmail normal
           ~500, Google Workspace/institucional ~2000).
         - "Recordar esta contraseña en este equipo": si la marcas, se
           guarda en ".constancias_cuentas_correo.json" en esta misma
           carpeta (texto simple, sin cifrar) para no pedírtela cada
           vez — solo actívalo en tu propia computadora. Si no la
           marcas, el programa te la pedirá la próxima vez que la uses
           (pero no cada tanda dentro de la misma sesión).
     • Cerrar sesión: "olvida" la contraseña guardada/en memoria de la
       cuenta seleccionada (el alias y el correo se quedan en la
       lista, solo te la vuelve a pedir la próxima vez).
     • Eliminar: la borra por completo de la lista (pide confirmar).

   Hay un botón "Usar todas" que selecciona todas las cuentas de un
   clic para repartir el envío entre ellas; o elige tú cuáles con clic
   (Ctrl+clic para varias, Shift+clic para un rango). La selección ya
   NO se desmarca después de generar, así que si vuelves a darle
   "Generar constancias" para mandar más, las cuentas que marcaste
   siguen marcadas.

   Si seleccionas más de una cuenta, el programa usa la primera hasta
   que llega a su límite diario, y ahí solito pasa a la siguiente, sin
   perder el lugar: si cierras el programa y lo vuelves a abrir el
   mismo día, se acuerda cuántos ya mandó cada cuenta y sigue justo
   donde se quedó (el conteo se reinicia solo al día siguiente).

   También elige la "Columna de correo" (se detecta sola si tu Excel
   trae una columna como "Correo" o "Email"). Al generar, además del
   PDF, se le manda un correo a cada persona con SU constancia adjunta.
   Si a alguien le falta el correo o está mal escrito, no se envía nada
   para esa persona pero el programa sigue con las demás normalmente
   (lo verás anotado en la consola de Progreso, incluyendo cuándo se
   cambió de una cuenta a otra por límite, o si todas las cuentas ya
   llegaron a su tope por hoy).

   MENSAJE DEL CORREO — automático o redactado por ti:
   Debajo de las cuentas hay dos opciones:
     • Mensaje automático: usa un título y texto genéricos ya
       incluidos ("Tu constancia de participación" / "Hola, adjunto tu
       constancia..."). No tienes que escribir nada.
     • Redactar el mío: aparecen dos campos para que pongas TÚ:
         - Título: el asunto del correo (puedes usar {nombre} aquí si
           quieres, ej. "¡Felicidades {nombre}!").
         - Mensaje: SOLO escribes el texto que va después del saludo.
           El saludo "Hola [nombre de la persona]," se agrega SOLITO al
           principio de cada correo — no hace falta que lo escribas ni
           que pongas {nombre} tú mismo, así nunca sale mal (repetido,
           genérico o sin personalizar). Si de todas formas quieres
           poner {nombre} en otra parte del mensaje, también funciona.
       Lo que escribas se recuerda para la próxima vez que abras el
       programa.

7) UN SOLO CÓDIGO QR EN VEZ DE UNA CARPETA (modo QR)
   Si nada más tienes un QR que colocar (no una tanda), en el modo
   "Códigos QR" elige "Un solo archivo" en vez de "Carpeta (varios)",
   y selecciona directamente la imagen del QR. Se genera una sola
   imagen PNG con ese QR ya puesto en la plantilla, nombrada igual que
   el archivo original — sin necesidad de meterlo a una carpeta.
   El modo "Carpeta (varios)" sigue igual que antes, para cuando sí
   tengas muchos QR de un jalón.

8) SELECCIONAR CUENTAS MÁS RÁPIDO
   Ver el paso 6 — el botón "Usar todas" y la selección que ya no se
   pierde entre tandas de envío aplican aquí.

9) ARRASTRAR Y SOLTAR ARCHIVOS (drag & drop)
   Si instalaste "tkinterdnd2" (ver el paso 1), puedes arrastrar
   archivos directo desde tu explorador de archivos hasta la ventana,
   en vez de darle a "Examinar…" — y NO hace falta soltarlo sobre un
   renglón exacto: puedes soltar en CUALQUIER parte del panel
   izquierdo (donde están los campos y la consola de Progreso), el
   programa adivina solo qué es cada cosa:
     • Un archivo .xlsx/.xls → se toma como el Excel (modo Constancias).
     • Una carpeta → se toma como la carpeta de QRs (cambia solo al
       modo "Carpeta (varios)" si hacía falta).
     • Una imagen → depende del modo:
         - En Constancias: siempre se toma como la plantilla.
         - En QR: si todavía no habías puesto plantilla, la primera
           imagen que sueltes se toma como la plantilla. Si ya tienes
           plantilla, el programa se fija si la imagen "parece" un
           código QR (cuadrada y de solo blanco/negro) — si parece QR,
           la usa como el QR individual (cambia al modo "Un solo
           archivo"); si no, la toma como una nueva plantilla.
   Si el programa adivina mal en algún caso raro, siempre puedes seguir
   usando los botones "Examinar…" normalmente para corregirlo.
   Si no instalaste "tkinterdnd2", no pasa nada: todo sigue funcionando
   igual, nada más no vas a poder arrastrar (usa "Examinar…" como
   siempre).

10) COMPILAR COMO .EXE PARA WINDOWS (opcional)
   Esto lo tienes que hacer TÚ en una computadora con Windows — no se
   puede generar un .exe de Windows desde Linux/Mac. Una vez armado,
   ese .exe ya no necesita que la persona que lo usa tenga Python
   instalado.

   Pasos (en tu terminal de Windows, con el mismo entorno virtual que
   ya usas para correr el programa activado):
       pip install pyinstaller
       python -m PyInstaller constancias_gui.spec --noconfirm

   Cuando termine (1-2 minutos), tu programa está listo en:
           dist\GeneradorConstanciasQR\
   Ahí adentro está "GeneradorConstanciasQR.exe" junto con
   plantilla.jpeg, datos_ejemplo.xlsx y todo lo que necesita.

   IMPORTANTE: reparte/copia esa CARPETA COMPLETA
   (dist\GeneradorConstanciasQR\), no solo el archivo .exe suelto — el
   programa necesita los archivos que están a su lado para funcionar
   (plantilla de ejemplo, y ahí mismo va guardando sus preferencias,
   cuentas de correo y salida cuando lo uses). Puedes comprimir esa
   carpeta en un .zip para mandarla a otra computadora, o meterla en
   una USB.

   Si algo sale mal y quieres ver el error exacto en una ventanita de
   consola (en vez de que la app se cierre sola sin avisar), abre
   "constancias_gui.spec" con el Bloc de notas, busca la línea
   "console=False" y cámbiala por "console=True", guarda, y vuelve a
   correr el mismo comando de arriba — así verás los mensajes de error
   mientras lo pruebas. Cuando ya funcione bien, puedes regresarlo a
   "console=False" para la versión final (sin ventana de consola negra
   detrás).

   Si quieres ponerle tu propio ícono al .exe, consigue un archivo
   ".ico", ponlo en esta misma carpeta, y en "constancias_gui.spec"
   quita el "#" de la línea que dice icon="icono.ico" (cambiando
   "icono.ico" por el nombre real de tu archivo).

11) ACTUALIZACIONES AUTOMÁTICAS (para cuando ya repartiste el .exe)
   El programa puede avisarle solo a quien lo esté usando cuando saques
   una versión nueva (corrijas un error, agregues algo), y actualizarse
   solo con un clic (en el .exe de Windows). Mientras no configures
   nada, esto está APAGADO — el programa nunca revisa nada por internet
   por su cuenta.

   CÓMO ACTIVARLO (una sola vez, gratis, usando GitHub):

     1. Crea una cuenta en github.com si no tienes, y crea un
        repositorio PÚBLICO nuevo (ej. "generador-constancias"). No
        hace falta que sepas usar git a fondo — puedes subir archivos
        directo desde el navegador con el botón "Add file" ->
        "Upload files".

     2. Sube ahí un archivo llamado "manifiesto.json" con este
        contenido (ajusta la versión y dale un enlace de descarga
        provisional, lo actualizas en el paso 4):
            {
              "version": "1.0.0",
              "url_zip": "",
              "notas": ""
            }

     3. Entra a ese archivo en GitHub, dale clic al botón "Raw", y
        copia la URL que se abre (algo como
        https://raw.githubusercontent.com/tu-usuario/tu-repo/main/manifiesto.json).
        Pégala en "configuracion_actualizaciones.py" (en esta misma
        carpeta), en la línea URL_MANIFIESTO = "...". Guarda, y
        vuelve a compilar el .exe (paso 10) — esto solo lo haces UNA
        VEZ, la URL ya no cambia después.

     4. Cada vez que corrijas algo o agregues una función nueva:
          a) Sube el número en el archivo "VERSION" (ej. de "1.0.0" a
             "1.1.0").
          b) Vuelve a compilar el .exe (paso 10).
          c) Comprime la carpeta dist\GeneradorConstanciasQR completa
             en un .zip (ej. "GeneradorConstanciasQR_v1.1.0.zip").
          d) Sube ese .zip a GitHub: en tu mismo repositorio, ve a
             "Releases" -> "Create a new release", ponle como tag la
             versión (ej. "v1.1.0"), y arrastra el .zip ahí. Al
             publicarlo, GitHub te da un link de descarga directo del
             .zip (clic derecho sobre el archivo -> copiar enlace).
          e) Edita "manifiesto.json" en GitHub (el mismo del paso 2) y
             actualiza "version" (a "1.1.0"), "url_zip" (con el link
             del paso anterior) y "notas" (una línea o dos explicando
             qué cambió, para que la gente la vea en el aviso). Guarda
             los cambios ahí mismo en GitHub.
          f) Listo. La próxima vez que alguien abra el programa (o le
             dé clic a Ayuda -> "Buscar actualizaciones ahora"), le va
             a aparecer un aviso con lo que cambió y un botón para
             actualizar solo.

   ALTERNATIVA sin GitHub: cualquier otro lugar donde puedas subir un
   archivo y obtener un link directo de descarga (Google Drive con
   "cualquiera con el enlace", tu propio hosting, etc.) también sirve
   — el programa solo necesita una URL que responda ese JSON al
   pedirla, no tiene que ser GitHub específicamente.

   IMPORTANTE sobre la actualización automática: solo funciona así de
   "un clic" en el .exe de Windows ya compilado (usa robocopy, que
   viene incluido en Windows, para reemplazar los archivos). Si
   alguien está corriendo el programa como script de Python normal, o
   en Mac/Linux, el botón "Actualizar ahora" no aparece — en su lugar
   ve "Descargar manualmente", que le abre el link del .zip en el
   navegador para que lo baje y reemplace la carpeta a mano.
